# ADR-006 — Versioned, source-traceable rules

**Status:** Accepted.

Mỗi catalog/criterion/formula/classification rule có version, hiệu lực, source reference, trạng thái draft/published/retired. Transaction giữ snapshot/version đã dùng.

Lý do: thay đổi văn bản không được làm biến đổi lịch sử điểm hay quyết định đã phê duyệt.
