# Demo plan — 12 minutes

## Demo objective

Show the reasoning chain, not a CRUD tour:

```text
source → rule → implementation → decision → audit
```

## Script

1. **1 min — source evidence**
   - open source matrix;
   - show FACT / INFERENCE / TBD;
   - highlight 05-HD arithmetic inconsistency as an example of not blindly coding a document.

2. **1 min — organization**
   - four departments;
   - demo person/position data marked synthetic;
   - responsibility trace to QĐ01.

3. **2 min — work catalog + assignment**
   - choose a versioned catalog item;
   - show product/complexity/time/source;
   - head assigns to a member;
   - audit entry created.

4. **2 min — execution**
   - staff opens inbox;
   - submits quantity/result/product + synthetic evidence reference;
   - system records completion time.

5. **2 min — KPI**
   - show A/B/C/D for a leader scenario;
   - show 30/70 breakdown and formula explanation;
   - display rule/source version;
   - explicitly mark candidate configuration if unresolved source issue remains.

6. **2 min — evaluation/classification**
   - self evaluation;
   - reviewer returns once, then reviews;
   - show score band plus mandatory-condition checks;
   - competent authority makes final decision.

7. **1 min — lock/security/audit**
   - lock period;
   - attempt forbidden edit/export;
   - show denied action/audit timeline.

8. **1 min — dashboard + architecture**
   - department/personal summary;
   - source trace;
   - architecture/security/future fake connector.

## Demo data

Only synthetic names/records/files. Do not demo real BVCTNB, health, state-secret or personnel records.

## Backup if feature is unfinished

Never fake a completed production capability.

Use one of:

- “Implemented” — demonstrate.
- “Designed” — show diagram + tests/contract.
- “TBD / gated” — show exact unresolved source/authority.

That distinction is itself part of the defense.
