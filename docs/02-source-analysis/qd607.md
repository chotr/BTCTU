## FACT — tài liệu nói trực tiếp

### 1. Ba phụ lục chính

1. Danh mục dữ liệu dùng chung của CSDL tổ chức đảng/đảng viên và CSDL cán bộ.
2. Đặc tả API kết nối/chia sẻ của CSDL tổ chức đảng/đảng viên.
3. Đặc tả API kết nối/chia sẻ của CSDL cán bộ.

Việc áp dụng API phải đúng phạm vi, mục đích, đối tượng tiếp nhận, mức độ chia sẻ và phân quyền đã được phê duyệt.

Nguồn: Điều 1–2, trang 2–3.

### 2. Xác thực tích hợp

Đặc tả sử dụng:

- OAuth 2.0 `client_credentials`;
- Consumer Key / Secret Key;
- `access_token` dạng JWT;
- `Authorization: Bearer <access_token>` khi gọi API nghiệp vụ.

Nguồn: phần xác thực của các phụ lục API, khoảng trang 11 và 30.

### 3. Yêu cầu an toàn khi gọi API

Đặc tả còn yêu cầu:

- sử dụng HTTPS với TLS từ 1.2 trở lên;
- không truyền dữ liệu cá nhân qua query string;
- không ghi log token, mật khẩu hoặc dữ liệu cá nhân.

Nguồn: các yêu cầu kỹ thuật/an toàn API trong Phụ lục 2–3.

### 4. Scope dữ liệu

- API dữ liệu cá nhân chỉ trả dữ liệu thuộc phạm vi quản lý/kết nối đã được phê duyệt.
- Một số API hệ thống-tới-hệ thống dùng token hệ thống.
- HTTP 401 biểu thị lỗi/hết hạn xác thực; 403 biểu thị token hợp lệ nhưng không đủ quyền/phạm vi.
- Không retry liên tục khi gặp 401/403; phải xử lý lại trạng thái xác
  thực/phân quyền theo contract.
- Quyền kết nối có thể bị tạm dừng/thu hồi nếu dùng sai mục đích, có nguy cơ ATTT hoặc không còn nhu cầu.

Nguồn: phần “Phạm vi khai thác dữ liệu”, khoảng trang 11–12 và 30–31.

## INFERENCE / design impact

- Đây là **integration contract**, không phải lý do để local database sao chép nguyên cấu trúc API.
- Dùng anti-corruption/connector layer:
  `API DTO → canonical mapping → local read model`.
- Credential của connector tách khỏi user session.
- Contract tests nên kiểm tra mapping/error handling 401/403/token expiry.
- Adapter cần test thêm transport/logging guard: TLS policy, không đưa dữ liệu
  cá nhân vào query string và redaction dữ liệu xác thực/cá nhân khỏi log.
- Demo dùng fake adapter; không dùng credential hay dữ liệu thật.

## SOURCE DIVERGENCE

QĐ607 dùng wording/contract cụ thể **OAuth 2.0 `client_credentials`**. HD07 mô
tả tầng LGSP rộng hơn với OAuth 2.1, OIDC 2.0, SAML2, JWT Federation và mTLS.
Không coi các cơ chế này là tương đương hoặc tự nâng/hạ version. Connector
production phải bám đúng contract của endpoint/platform được phê duyệt.
